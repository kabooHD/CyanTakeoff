# CyanTakeoff

A free, open-source PDF markup, measurement and takeoff application for the
construction industry, built so that people who use Bluebeam Revu today can
switch with almost no retraining.

> Status: planning. See [docs/PLAN.md](docs/PLAN.md) for the full plan,
> architecture and roadmap.

CyanTakeoff is an independent project and is not affiliated with, endorsed by,
or derived from Bluebeam, Inc. "Bluebeam" and "Revu" are trademarks of their
respective owners and are used here only to describe compatibility goals.
